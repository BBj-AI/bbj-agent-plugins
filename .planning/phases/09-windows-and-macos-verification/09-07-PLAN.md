<objective>
Turn the owner's macOS readings into the record, ask fix-or-gap for each macOS defect, and build
the chosen fixes with CI gates on fakes (PLAT-05, PLAT-06; D-05, D-08, D-09, D-10, D-12, D-16).
This is the macOS counterpart of plan 09-05.

PLAT-05 asks for tier 1: `bbjcpl` feedback. The 0.2.0 UAT showed only tier 2 on this Mac, because
BBj was not installed then. So a `bbj-local reported` header for a bad file means the hook did not
find the compiler, and that counts as a defect, not a pass.

No `cygpath` and no PowerShell apply on macOS. The two optional smoke readings (tier 2, no-route)
are recorded as optional readings, not requirements (D-16).
</objective>
