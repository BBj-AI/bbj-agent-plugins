<objective>
The owner's second session (D-09, D-03, PLAT-05 input, PLAT-01 to PLAT-04 closure on Windows). It
has two parts:
- Part A, on Windows, only when plan 09-05 shipped a fix or planned a capture: the owner re-runs
  exactly the routes `## Defects and re-runs` names. Each re-run gets a second dated reading under
  the same section, and the Windows verdicts become final.
- Part B, on the Mac: the macOS pass of macos-runbook.md. It needs BBj with `bbjcpl` installed on
  the Mac (the STATE blocker). Without it the plan stops; it does not record PLAT-05 as anything.

Both parts use the commit this plan transfers, after the Linux suite is green (D-09). Doing the Mac
after the Windows fixes means the macOS readings are taken on the hook definition that ships. With
a `commandWindows` entry the hook hash differs from the earlier commit, and the macOS trust step
sees the final hash.
</objective>

  the smoke header against the cache (`cache-identical`). When the copy differs, the owner removes
  the plugin and adds it again before the readings count.

| T-09-25 | Elevation of Privilege | a run that executes BBj | high | mitigate | All owner steps reach a compiler only through the hook (`-N`, static gate); the preflight uses the fake compiler only |
</threat_model>
