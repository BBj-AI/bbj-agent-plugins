## Shared Patterns

### Compile-only, never run
**Source:** `04-.../probes/run.py` lines 36-41, 134-149 and `tests/test_never_execute.sh`.
**Apply to:** all probes and owner repros. Every compiler call carries `-t -N -X`; loopback `bbj-ls` only; the hosted `bbj_check_syntax` is never sent skill or probe code. Owner repros are compiled by Claude, run only by the owner.

### Gate-line output
**Source:** `ledger_check.py:60-64`, `run.py` prints.
**Apply to:** `ledger_check.py`, `run.py`: `gate <prefix>_<name> ok|FAIL <detail>`, `safe()` strips non-ASCII, `python3 -I`, stdlib only, module docstring stating what it locks and "Nothing here runs BBj".

### Evidence rule
**Source:** `04-LEDGER.md` lines 41-50 and `04-DOCS-PROPOSAL.md` intro.
**Apply to:** ledger, skill text, docs proposal: DOC evidence is the body of an official page file; search results labelled "not a citable page", spliced text, and primer paragraphs are never DOC evidence. Shipped sentence must not say more than the quoted source (RESEARCH P3).

### Example-fence rules
**Source:** Phase 3 gate `tests/test_skill_examples.py`; `NON_BBJ = ("css","html","js","json","bash","sh","text","xml")` at line 130.
**Apply to:** SKILL.md and all references: no `bbj nocheck`; wrong code only in `bbj should-fail`; `; rem` for same-line comments; no `...`; denylist strings absent (`DailyDrift`, `DriftDB`, `migrateSortPrefs`, `watches!`, `cart-updated`, `/opt/basis/bin/`).

### Dry-run before commit
**Source:** `04-.../probes/README.md` lines 50-62 (scratch root with empty `pending` baseline):
```text
ROOT=<scratchpad>/skill-root
```
