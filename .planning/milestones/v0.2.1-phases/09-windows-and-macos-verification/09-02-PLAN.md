<objective>
Build the smoke script the owner runs on Windows (Git Bash) and macOS (`/bin/sh`). It is a small
POSIX `sh` driver that feeds the shipped hook the payloads Claude Code and Codex send, against the
real `bbjcpl` of the machine. It prints result blocks the owner pastes back (D-01, D-04, D-06,
D-07, D-14, D-16; RESEARCH Patterns 2 and 3, Pitfalls 2, 5, 6, 8 and 10).

It is not CI and not a test: it lives beside the records, like Phase 8's `linux-run/`, and never
runs BBj. It reaches the compiler only through the hook, so every call carries `-N`. The client
steps (install, trust, real writes) are the owner's runbook (plan 09-03); this script covers what
a script can show without a client: the exact compiler call on real paths (PLAT-02), the hook's
verdict for each payload form (PLAT-01, PLAT-03, PLAT-05), tier 2 over loopback (PLAT-04, D-14),
and the no-route claim on the machine's file system (D-16).

Output: `.planning/phases/09-windows-and-macos-verification/platform-run/smoke.sh`, proven on Linux
with the fake compiler under dash and `bash --posix`.
</objective>

2. Set-up, in this order:
   - `CHECKOUT=$(cd "$(dirname "$0")/../../../.." && pwd)`;
   - read the caller's home before `tests/lib.sh` clears it:
     `KEEP_HOME=${SMOKE_BBJ_HOME:-${CLAUDE_PLUGIN_OPTION_BBJ_HOME:-${BBJ_HOME:-}}}`, plus a

   - source `$CHECKOUT/tests/lib.sh`, then call `mkwork`;
   - `WIN=1` when `command -v cygpath` succeeds, else 0;
   - helpers `w PATH` (`cygpath -w` when WIN=1, else the path unchanged) and `m PATH`
     (`cygpath -m` when WIN=1, else unchanged), each printed with `printf '%s'`;
   - `kv KEY VALUE` printing `KEY: VALUE`.

3. `scrub` (a filter from stdin to stdout).
   - One awk program. It reads every path from ENVIRON, never through awk's command-line variable
     assignment, which would read the `\U` of C:\Users as an escape.
   - Use a literal-substring replace function built on `index()` and `substr()`, never a regex.
   - Order of the replacements:
     1. protect the BBj home (replace it with a sentinel);
     2. the checkout in its three forms (POSIX, `w`, `m`) becomes `<checkout>`;
     3. WORK in its three forms becomes `<work>`;
     4. HOME in its three forms becomes `<home>`;
     5. restore the sentinel to the BBj home.
   - Empty forms are skipped.
   - The BBj home is protected only when it does not start with any form of HOME. Otherwise it is
     scrubbed like any other path, and its home part becomes `<home>` (D-07: the user name never
     leaks through a BBj home under the home directory).

4. `header NAME` prints these keys, then a blank line, all through `scrub`:
   - `smoke` (NAME); `date` (`date +%Y-%m-%d`); `platform` (`uname -sr`);
   - `shell` (`${BASH_VERSION:-unknown}`); `hook_shell_version` (the output of
     `$SHELL_UNDER_TEST -c 'printf "%s" "${BASH_VERSION:-unknown}"'`); `cygpath` (yes or no);
   - `checkout_commit` (`git -C "$CHECKOUT" rev-parse --short HEAD`, or `unknown`);
   - `hook_script` (SCRIPT); `hook_script_cksum` (the first field of `cksum < "$SCRIPT"`);
   - `script_identical_to_checkout` (`cmp -s` with `$CHECKOUT/plugins/bbj/scripts/bbj-check.sh`,
     yes or no);
   - `hooks_json_identical_to_checkout` (`cmp -s` of `$ROOT/hooks/hooks.json` with the
     checkout's, yes, no or absent);
   - `hooks_json_command` (`hook_cmd`, below);
   - `bbj_home` (KEEP_HOME or `none`); `discovery_source` (DISC_SRC).

5. `hook_cmd`: prints the command string of `$ROOT/hooks/hooks.json`. Use `sed -n` on the line

   each `\"` back into `"`. Print nothing when the file is absent.

6. `mkproj DIR`: run `mkdir -p "DIR/sub"`, then write with `printf '%s\n'` the bad line to

7. `case_run NAME FILE-AS-SENT CWD-AS-SENT PAYLOAD`:
   - Run `run_check "$PAYLOAD"`. Read the first stderr line with `\r` removed.
   - Run the hook a second time on `$WORK/payload` with
     `PS4='+TRACE ' $SHELL_UNDER_TEST -x "$SCRIPT"`, stdout to /dev/null and stderr to
     `$WORK/trace`.
   - Take the last trace line that contains ` -t -N -X`, with the leading `+` run and `TRACE `
     removed, as `compiler_call` (or `none`). `dash_n` is yes when that line holds ` -N `.
   - When `hook_shell_version` is not `unknown` and the line is not `none`, split it with an awk
     tokenizer that honours single quotes and backslash-escaped quotes.
     - When token 2 to 4 are `-t -N -X`, print `compiler` (token 1). When token 5 starts with
       `-P`, print `p_list` (token 5 without `-P`) and `target` (token 6). Otherwise print
       `target` (token 5).
     - Else print `derived: none (unquoted trace)`.
   - Print `case`, `file_as_sent`, `cwd_as_sent`, `compiler_call`, the derived keys, `dash_n`,
