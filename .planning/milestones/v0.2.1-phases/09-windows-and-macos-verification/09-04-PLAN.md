1. Prove on Linux that the owner's path works: a fresh clone of HEAD runs the smoke script, and
   the suite is green (D-09 precondition).
2. Ask the owner the phase's first question: how the commit reaches the Windows machine and the
   Mac (RESEARCH Open Question 1, D-03).
3. Hand over the Windows runbook as one blocking human step, and record the reply (PLAT-01 to
   PLAT-04 evidence; D-02, D-04, D-06, D-07).

Why the transfer is a question: D-03 says the install source is a local clone of
`gsd/planning-setup`, that the record names the commit, and that "nothing is pushed for the runs".
`origin/gsd/planning-setup` is 25 commits behind the local branch, and the smoke script and every
later fix are local commits too (RESEARCH Pitfall 9). A clone from GitHub cannot see them. The
recommended default keeps D-03 as written: a `git bundle` file the owner copies to the machine.
The executor never pushes unless the owner chooses it.

Not here: writing the route sections, deriving defects and the fix-or-gap question. Those are
plan 09-05. This plan records the reply verbatim (scrubbed) and the environment table only.
</objective>
