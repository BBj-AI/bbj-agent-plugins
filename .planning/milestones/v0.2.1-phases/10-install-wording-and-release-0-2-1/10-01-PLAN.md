<objective>
Fix the installer's Windows hook command and give users with Git for Windows elsewhere a way in.
The tracer changes the one line that builds `commandWindows` to the PowerShell call form and pins
the whole string on the fake `cygpath` (D-06). The expansion adds `--sh-exe PATH` (D-08), the early
refusal for an sh.exe that cannot work (D-07), a fake-cygpath seam for the conversion failure, and
the gates that prove each case, including that `--remove` is never trapped.

under Codex's launcher (hook exit 1, nothing on stdout). The wording of plans 10-06 and 10-07 may
claim the installer on Windows only after the owner's re-run of this fix (D-09, plan 10-05).
Output: the fixed installer, its gates, and one new fake seam. Decisions: D-06, D-07, D-08 (the
option name `--sh-exe` is the planner's pick, CONTEXT "Claude's Discretion").
